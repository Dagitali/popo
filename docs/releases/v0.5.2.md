# Popo v0.5.2

Version 0.5.2, tagged on 2026-10-06 (UTC), routes routine Dependabot updates through `develop` and
backfills the 0.5.1 release history. The intended tag is `v0.5.2`; this record does not establish
tagging or publication.

## Highlights

- Target `develop` for Dependabot version updates across all three configured ecosystems.
- Backfill the dated 0.5.1 changelog entry, release record, and archive entry.
- Normalize historical release dates, status, structure, and validation evidence boundaries.

## Change Scope

The candidate adds `target-branch: develop` to the GitHub Actions, pip, and pre-commit blocks in
`.github/dependabot.yml` and updates its explanatory comments. README documents activation and
security-update routing. Changelog and release records document 0.5.1 and this candidate. Historical
records normalize UTC tag dates, tag status, template sections, and recorded validation boundaries.
Existing update schedules, dependency groups, and hook revisions are preserved.

## Compatibility and Configuration

No Popo CLI or consumer-configuration changes. Dependabot version-update PRs target `develop`;
security-update PRs continue targeting the default branch. Merge the configuration into the default
branch so GitHub can read it, and retain reviewed integration and required checks. This change does
not configure automatic merging or hosted repository rules.

## Support Boundary

No support-boundary changes. Python remains `>=3.13,<3.15`; runtime dependencies and package version
derivation retain their existing configuration.
