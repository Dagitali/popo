# Popo v0.8.1

Version 0.8.1, tagged on 2026-10-23, refactors policy checks and test suites and fixes malformed
input handling. This retrospective record backfills the release's missing documentation; publication
is not established by the local tag.

See the [changelog] for this version's concise change list.

## Change Scope

Share safe YAML loading and iterative mapping traversal across automation, actionlint and safety
checks, preserving traversal order and handling recursive/reused aliases without crashes or repeated
diagnostics. Consolidate CLI parser setup and configuration string-array validation, modernize type
aliases and complete class-based unit suites while retaining consumer-specific policy differences.

Read shared Python-policy metadata once, report unresolved workflow versions even alongside valid
declarations, and return diagnostics for malformed dependency project tables. Preserve dangling
header symlinks for containment checks, continue after required-file inspection errors, and stream
header scanning without losing supported syntax or consumer directives.

Split hosted configuration, adapter and CLI suites by scope; share evidence fixtures and expand
regressions. Installed wheel/sdist tests cover both entry points, independent passing/failing file
policies, unchanged consumer inputs and exact artifact-version output.

## Compatibility and Configuration

Public commands and configuration schemas remain available, and validators remain read-only.
Safety-exception expiry strings must use canonical `YYYY-MM-DD`; compact and ISO week dates are now
rejected. Unresolved workflow Python-version expressions are reported even when another version
declaration is valid. Correct these inputs before adoption; stricter validation can change
previously passing checks to failures. File-policy checks remain opt-in.

### Breaking Changes

No command or configuration schema is removed. Compatibility details are described above.

### Deprecations

No deprecations are recorded for this release.

## Support Boundary

Python remains `>=3.13,<3.15`. Runtime dependencies, distribution formats and publication safeguards
are unchanged. Python 3.15 support is outside this release.
