# Popo v0.3.1

Version 0.3.1, tagged on 2026-09-30 (UTC), aligns and generalizes Popo's root documentation. It
covers the complete `feature/align-root-documentation` branch since `v0.3.0`. This retrospective
record is prepared in the 0.3.2 hotfix; it was not present in the original tag. See the [changelog].

## Highlights

See the [changelog] for this version's concise change list.

## Change Scope

The release changes all 14 root Markdown documents. It adds the nine guides above and updates
`AGENTS.md`, `CONTRIBUTING.md`, `README.md`, `RELEASE-POLICY.md`, and `CHANGELOG.md`. Guidance
covers component ownership, configuration evolution, validation layers, workflow responsibilities,
troubleshooting, compatibility review, community participation, and publication readiness.

The branch also repairs attribution and tooling references, normalizes reference ordering, and
clarifies current guidance versus historical evidence. It preserves purposeful differences from
consumer repositories, including configurable PR routing and optional publication. Package source,
tests, dependencies, configuration, and workflow implementation are unchanged.

## Compatibility and Configuration

No compatibility or configuration changes. Commands, flags, diagnostics, exit codes, and consumer
settings retain their existing behavior. No migration is required.

## Support Boundary

No support-boundary changes. Python remains `>=3.13,<3.15`, with `packaging>=26.3,<27` and
`PyYAML>=6.0.3,<7`. The new guides clarify existing boundaries without introducing response
deadlines, backport guarantees, cloud operations, or PyPI publication.

## Validation

Consequently, that tagged file fails the release-changelog requirement. The correction in 0.3.2 does
not repair the immutable 0.3.1 tree or prove a hosted workflow outcome.

Earlier development checks are not represented as validation of the exact tagged artifact. Hosted
cross-platform results, artifact integrity, and publication have not been verified for this record.
