# Popo v0.3.5

Version 0.3.5, tagged on 2026-10-01 (UTC), completes and standardizes Python docstrings across
source and tests. This patch release covers the complete `feature/complete-python-docstrings` change
set since `v0.3.4`, plus its release documentation. The tag does not establish hosted validation or
publication. See the [changelog].

## Highlights

See the [changelog] for this version's concise change list.

## Change Scope

The feature expands documentation in `src/popo/` and `tests/`, adds the docstring line-length
convention to `AGENTS.md`, and records the changes in `CHANGELOG.md`. The tagged changelog moves
those entries into the dated 0.3.5 section. This record and its archive entry were backfilled in
0.3.6; they are absent from the original 0.3.5 tag.

Docstring changes preserve executable behavior. NumPy section declarations and intentional public
package exports remain intact. No new Sphinx build or documentation dependency is introduced.

## Compatibility and Configuration

No compatibility or configuration changes. CLI commands, flags, diagnostics, exit codes, consumer
settings, dependency constraints, and workflow behavior remain unchanged. No migration is required.

## Support Boundary

No support-boundary changes. Python remains `>=3.13,<3.15`. Internal checker references in Sphinx
markup do not create a promised consumer API; the public CLI remains the adoption interface.

## Validation

Interpret these results using the [evidence boundaries].

Local validation on 2026-10-01 passed against the 0.3.5 working-tree candidate:

- `make release-changelog RELEASE_VERSION=v0.3.5` found the matching dated entry.
- `make check` passed lint, formatting, strict typing, all 274 unit/integration tests, and
  configured repository checks.
- `make docs-markdown` passed local link and heading-anchor validation.
- `git diff --check` passed.

Artifact and clean-installation checks were not run during this documentation correction; `make
check-release`, eventual tag-version agreement, and hosted validation remain pending. The repository
has no configured Sphinx build, so rendered cross-reference resolution has not been validated. Local
checkout results do not establish publication.
