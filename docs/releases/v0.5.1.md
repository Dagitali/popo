Version 0.5.1, tagged on 2026-10-06 (UTC), documents the pre-commit hook updates in that tag; it
does not establish hosted validation or publication. The original tag lacks its dated changelog
entry and release document; both are backfilled in the planned 0.5.2 release without modifying the

## Change Scope

The tagged diff from 0.5.0 changes only the two revisions in `.pre-commit-config.yaml`, introduced
through [Dependabot PR #4]. Existing hook stages and arguments are preserved. This release does not
include the subsequent Dependabot target-branch configuration or this retrospective record.

## Compatibility and Configuration

No Popo CLI or consumer-configuration changes. Commands, diagnostics, exit codes, and runtime
dependencies retain their 0.5.0 behavior. Contributor hooks use the updated tool revisions; no
consumer migration is required.

## Support Boundary

No support-boundary changes. Python remains `>=3.13,<3.15`. Hook revisions do not change Popo
package dependency constraints or establish new support commitments.
